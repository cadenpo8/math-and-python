# math-and-python
A collection of my Python projects exploring mathematics, calculus, and numerical methods. 


Hello, I started a good bit of these in 8th grade and have been working on new things all the way until my current sophomore year (2026-2027). Many of these project are not perfect as I am self taught. You may also notice that I am not importing many functions, I prefer with smaller mathematical codes to do it myself as it also helps me grasp the idea. I created this to document my progress throughout the years and explore mathematical concepts through coding.

Featured Projects:
### [Newton's Method] (https://github.com/cadenpo8/math-and-python/blob/main/projects/mathematical_computing/newtons_method.py) 
This has to be my favorite project, it is a rooting finding program that uses a user-inputted polynomial, then differentiates it and iterates numerical approximations for solutions of the polynomial equation.
